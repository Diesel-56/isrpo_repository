# Общее описание решения
## Описание функции square

**Функция square:**
'''
int square(int x) {
    return x * x;
}
'''

Функция запрашивает на вход одно целое число (длину стороны квадрата), а возвращает квадрат этого числа (площадь квадрата).

*Пример вызова:*
'''
int x;
std::cin >> x; // x = 5
std::cout << square(x) << std::endl; // Вывод: 25
'''


## Описание функции triangle

**Функция Функция square:**
'''
double triangle(int h, int n) {
    return h * n / 2;
}
'''

Функция запрашивает на вход два целых числа (высоту треугольника и длину стороны треугольника, на которую падает эта высота),
и возвращает площадь треугольника, по формуле h * n / 2 - где h - высота, n - сторона треугольника.

*Пример вызова:*
'''
int h, a;
std::cin >> h >> a; // h = 5, a = 3
std::cout << triangle(h, a) << std::endl; // Вывод: 7.5
'''
