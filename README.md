## Лабораторная работа №4 — Unit-тестирование

Добавил файл `tests.cpp` с 10 автоматическими проверками функций `square()` и `triangle()` из `area.cpp`. Для тестов используется простой тестовый исполнитель.

Запуск на macOS из корня репозитория:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic tests.cpp -o tests
./tests
```

Ожидаемый итог: `Result: 10 passed, 0 failed`.
