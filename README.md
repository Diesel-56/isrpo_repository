# Лабораторная работа №2 - *«Документирование»*

Программа на языке **C++**, которая запрашивает у пользователя параметры фигур
и вычисляет площадь **квадрата** и **треугольника**.

## Структура проекта

```
isrpo_repository/
|-- docs/
|    |-- document.md   // подробная документация проекта
|-- area.cpp          // исходный код программы
|-- README.md         // описание репозитория
```



## Пример работы

```
Введите длину стороны квадрата
5
Площадь квадрата: 25
Введите длину высоты, и стороны треугольника, на которую падает эта высота
4 3
Площадь треугольника: 6
```

**Пример вызова:**

```
std::cout << square(5) << std::endl;       // Вывод: 25
std::cout << triangle(5, 3) << std::endl;  // Вывод: 7.5
```
